# Majlis Canvas - لوحة المجلس

لعبة الرسم والتجسس التفاعلية بأسلوب مجلس عربي فاخر

## الميزات

- 🎨 لوحة رسم تعاونية مع متزامن مباشر
- 🕵️ نظام المزورين مع مهام منطقية
- ⏱️ أدوار رسم مدتها 30 ثانية
- 🗳️ نظام تصويت مع فرصة المحاولة الأخيرة
- 💬 دردشة مباشرة في الوقت الحقيقي
- 🎯 150 كلمة عربية مضحكة
- ✅ 30 مهمة منطقية غير مدمرة

## التقنيات

- Next.js 15 App Router
- TypeScript
- Tailwind CSS
- Socket.io

## التشغيل

```bash
npm install
npm run dev
```
